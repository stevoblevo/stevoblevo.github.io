Storeybrook

A light-first kit for storybook pages and little games: watercolor paper, pages that turn, stories read aloud, a brook of stones to walk, and nougats that fly into a jar.

Files

  • tokens.cssevery token as a custom property; looks as [data-theme] blocks; a class per type style
  • bundle.cssevery component, prefixed sb-, with the look hooks and the font import
  • bundle.jsone classic script, no dependencies, no network: window.Storeybrook
  • index.d.tsthe markup contracts and the API, as types
  • tokens.jsonthe tokens as data, in every look
  • storeybrook-tokens.cssfor a host with its own theme: tokens keyed on [data-sb]
  • storeybrook.cssthe components keyed on [data-sb], without the font import
  • storeybrook.jsthe same bundle, for the embedded export

Fonts come from Google Fonts. Load only the families your looks use.
