THE BIT THAT SHOULD HAVE BEEN CLEAR

Three folders.
Not one mystery directory.

Typical paths are examples, not a scan of your PC. Inspect an existing OBS shortcut’s Target instead of guessing.

▱01 / APP

What runs.

OBS program files. Not the place to save your clips.

C:\Program Files\obs-studio\
▱02 / SETTINGS

What remembers.

Scenes, profiles and configuration. Keep this private and backed up.

%APPDATA%\obs-studio\
▱03 / RECORDINGS

What you made.

Choose this in OBS → Settings → Output → Recording Path.

%USERPROFILE%\Videos\OBS

The recording path is a suggestion, not OBS’s detected default. Create that folder in File Explorer or choose another writable location with enough space. Expand %USERPROFILE% in File Explorer; use Browse in OBS to select the actual folder.

What changes in Portable mode?

Extract the official ZIP into a writable user folder, not Program Files. Place an empty portable_mode.txt beside the extracted top-level folders, then open the appropriate executable; the x64 layout uses bin/64bit/obs64.exe. Settings stay with that copy. Media and recording paths do not automatically become portable.

Lost a folder? Don’t start by deleting one.

“Where is OBS?”

Inspect the shortcut’s Target or use Open file location. Custom and portable installs may be elsewhere.

“Where is my clip?”

Read Recording Path in Settings → Output. Stop the recording, then open that folder—not the app folder.

“What about my setup?”

Preserve scenes and profiles before changing installs. Configuration may contain private connection details. Do not publish it.
