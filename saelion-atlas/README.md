# Saelion · Atlas of Worlds

A public-facing, manually curated atlas of Saelion/Anewgam worlds and hands-on experiments.

Source of truth for **this public directory**: `worlds.json`; original source code and native verification are maintained in their own repositories or private creative libraries. Do not treat the existence of an atlas card as evidence of publication or worker admission.

## Context

- `saelion.co/ways` remains the existing official public directory and front door. This adjunct atlas does **not** replace it.
- `nic-lan/` and `and-so/gamut-43/` contain source-preserved editions of the two newly supplied interactive experiences.
- `and-so/` preserves the older published singing/microphone edition.
- **open** means observed reachable public URL at the stated checkpoint, not independently reviewed in every browser.
- **design** and **dream** have no play-button or invented public URL.
- Never publish private ChatGPT Library IDs, device LAN IPs, credentials, raw user archives or worker receipts into the public atlas.

## How to use

Open `index.html` under a local HTTP server or as GitHub Pages. Filter by activity or search. The page fetches `worlds.json` from its own directory.
